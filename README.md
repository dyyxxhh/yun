# 等你出呢

他醒来时，放学铃刚响过。

这一觉睡得胳膊发麻。夕阳横在桌面上，照着半块橡皮、一支没盖帽的笔。黑板右下角写着作业，最后一道题只抄了题号，像写字的人急着走。

书包不在桌洞里。他想，大概又被藏到了后排。

走廊传来一声拍手。

隔了一会儿，又是一声。

他把笔揣进口袋，走出去。隔壁班门开着，桌椅挤到两边，中间空出一小块地方。课间他们常在这里围成圈，拍一下手，同时出一个手势；输了的退到旁边，催还在攒运的人快一点。

现在里面没人。

他敲敲门框。

“还玩呢？”

没有回答。窗帘垂着，底边被撕掉一截。

他在后门找到了自己的书包。拉链坏了，露出里面蓝色的作业本。提起来时，提手断在掌心，书包落地，扬起一层灰。

他蹲下去，手指碰到硬脆的布料。

这包早上背来的时候还好好的。

拍手声又响了，就在头顶。

他猛地起身，后脑撞上桌沿。疼得眼前一黑，过了半晌才缓过来。桌面上压着一张玻璃，底下是值日表，纸黄得看不清格子。右上角有人画了只乌龟。

他记得这只乌龟。最后一笔是上节自习添的，老师转过身，他赶紧把手缩回去，指尖还蹭了墨。

他摊开手。食指侧面干干净净。

楼下响起铁链拖动的声音。

他走到楼梯口，喊了声等一下。底下有手电光晃过，一个穿工作服的人正拉开卷闸门，另一个男人站在门外，腋下夹着黑色皮包。

“上面看过了？”穿工作服的问。

“看过了。”

“那我封门。明早拆窗户，别再有人进来。”

他往下跑。楼梯转角原本挂着的流动红旗不见了，墙上剩一个颜色浅些的三角。再往下，是一块掉了漆的牌子：旧教学楼，禁止入内。

他停在牌子前。

每天早上，他都从这里上楼。他不记得有这块牌子。

门外的男人回过头，朝上面望来。他认得那双眼睛，却一下叫不出称呼。男人鬓角已经白了，衬衣领口露出一小截疤。

以前也有个人，领口总不肯扣好。体育课摔破锁骨下面那块皮，结了痂还去抠。玩游戏时，那个人就站在他对面，每次轮到他想太久，便歪着头说——

“等你出呢。”

声音从楼上传下来。

门外的男人低下头，掏出手机。他朝男人走过去，想问问刚才那句话是不是他说的。屏幕恰好亮着，日期下面是一张合照：几个中年人站在校门前，笑着指向镜头。

那个领口有疤的也在里面。

他看了日期很久。教室后墙那张高考倒计时上的年份，他每天都看，不会记错。

年份差了二十多年。

“走不走？”穿工作服的人催。

男人把手机放回口袋，抬头看了看二楼。

“这门以前不锁的。”

“以前是以前。”

他伸手去拦，手掌停在男人袖口前。布料上有一根细线，随着呼吸微微起伏。他忽然害怕碰到它。

铁门合上了。

他仍站在楼梯口。楼上响了一声拍手，这次听得很清楚，没有回音，干干的。

他低头，看见自己的双手正慢慢分开。

掌心发红。

有些事情这才接了起来。

那天放学，他们约好最后一局。他不肯随便出，怕把攒了半天的运浪费掉。有人背上书包，有人催晚饭，有人笑着说那你慢慢想。

他低着头算。等到终于抬头，圈里只剩他一个。

他以为他们躲起来了。

于是去隔壁班找，去后门找，去楼梯口找。找累了，就回座位趴一会儿。每次醒来，铃声刚停，夕阳照着没抄完的题号。

楼下的人换过很多次。最初穿校服，后来穿衬衫。有一回还牵着孩子。只有他一直觉得今天的书包被人藏了。

他回到隔壁班。

空地比记忆里小。几张桌子腿朽了，歪斜着抵在一起，没人站得进来。他在靠窗的位置坐下，那是当年自己站着的地方。

右手还想往左手上拍。他把它按在膝盖底下。

桌洞里有一本薄册子。封面朝下，书脊用透明胶粘过，胶带早已变成褐色。翻开的那页密密麻麻写着字，页边留了一句：明天接着玩。

最后那个句号戳破了纸。

他把口袋里的笔拿出来。笔尖早干了，在旁边划不出痕迹。他记得写这句话时，大家抢着补充漏掉的地方，有人把桌子拍得直响。他嫌吵，用笔狠狠点了一下。

窗外最后一点亮光退到纸边。楼下传来锁链收紧的声音，他把册子翻回正面，认出了自己总把最后一捺拖得很长的字——[大运规则文档](rules.md)。
